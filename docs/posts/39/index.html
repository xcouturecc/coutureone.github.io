深夜流水账：长跑、网络折腾与AI时代的胡思乱想写点东西

Updated atMay 19, 2026

晚上跑了10 公里，最近积压的事情有点多，躺在床上脑子里也跟着胡思乱想，睡不着。

深夜十二点半，一个人坐在电脑前敲下这些文字，其实我也不知道自己究竟想写些什么，全当是给大脑做一次碎片清理。

周末的“网络考古”与 AI 工具横评

这周六日，我把大把时间耗在了折腾家里网络上，主要是为了彻底解决 DNS 泄露的问题。

折腾期间，我顺便做了一组“AI 盲测”——让 DeepSeek、Gemini 和 ChatGPT 去解决同一个网络坑。结果挺有意思，ChatGPT 完胜，剩下两个在复杂网络排错上还是差点意思。

最近我也开始尝试用 Hermes 来处理一些琐碎的自动化任务，不得不说，现在的 Agent 确实进化得越来越聪明了，常规问题基本能让人当个“甩手掌柜”。但作为技术牛马，安全与权限分配也是我最担忧的漏洞：

  • 失去约束的风险：没有严格限制的 AI 可以直接化身黑客攻击服务器。
  • 隐私越界：像 Hermes 这类 Agent，如果权限全开，它能肆无忌惮地读取和操作你本地的所有文件，甚至连网盘里的 iCloud 和 OneDrive 都能直接访问。

我的解法是：在安装和配置阶段必须严控权限。涉及敏感操作时，每一次下发指令都需要人工确认，并将其作为铁律固化到 Agent 的长效记忆当中。

关于“断更”两个月的周志反思

原本计划是每周写一次复盘的，今天去翻了一下 GitHub Issues 里的周志，才猛然发现自己居然已经断更了快两个月。

看来，习惯这东西确实没那么容易刻进DNA。为了拯救这个好习惯，我打算在提醒清单里加一条Tips：每周日下午定时提醒。本周末重新开张。

跑步：500km 进度条即将过半

聊点有成就感的事。今年的跑步目标是 1000km，目前马上就要解锁前 500km 了。

虽然过程是漫长的积累，但只要步子不停，跑着跑着，终点也就近了。

现在脑子其实不想思考任何事了，只想睡觉。

事实证明，深夜真的不能跑长距离，多巴胺分泌过盛导致现在整个人处于一种诡异的亢奋状态。我已经能提前预想到明天自己靠黑咖啡疯狂续命的惨状了。

稀里糊涂写了一堆，碎碎念结束。

关机，睡觉。
